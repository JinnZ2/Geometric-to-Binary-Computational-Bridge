# Experiment bridge v1 contract — 2026-11-17

This is a new, separately versioned nonphysical experiment. All raw inputs, as-received scripts, archived outputs and prior audit findings remain unchanged. Numerical selection, semantic annotation and transport are independent. No code index is assumed to mean a Lojban word; no threshold is attributed to NCM dropout. Handwritten demonstration vectors are ILLUSTRATIVE test fixtures, not empirical semantics.

## Module boundaries

`core.py` owns checked numerical RVQ. Its public API is `make_level(codebook, threshold_squared, label="") -> Level`, `walk(target, levels) -> dict`, and `calibrate_thresholds(samples, codebooks, rejection_fraction, gated=True) -> tuple[float, ...]`. Inputs must be nonempty finite compatible real vectors (not bool), nonempty finite codebooks, and finite nonnegative squared-distance thresholds. Dimensions and level counts are validated. Fixed ordering breaks exact ties. Rejection emits code_index=null, zero contribution, unchanged residual, and numerical_status=REJECTED. Acceptance can still have missing semantic assignment. The trace dictionary has `version="experiment-bridge/v1"`, target, dimension, steps, reconstruction, residual. Every step preserves `level`, `codebook_sha256`, `nearest_index`, `code_index`, `distance_squared`, `threshold_squared`, `numerical_status`, contribution, reconstruction_before/after, residual_before/after and squared residual errors. Step transitions are independently checkable; squared-error decrease is not assumed. No reserved zero vector competes as a rejection token.

`semantics.py` owns a lossless role-aware reference view. API: `normalize_reference(data) -> list[dict]`, `find_rows(rows, identifier=None, english=None, role=None) -> list[dict]`, and `annotate_trace(trace, rows, assignments=None, evidential_row_id=None) -> dict`. Raw data is neither changed nor reclassified. Normalized rows retain the entire source row under `source`, carry `row_id` stable for identical content/role/occurrence, identifier, role (mapping/recall_check/evidential), lexical_status (PRESENT/LEXICAL_VOID), and source collection/index. Repeated identifiers never overwrite distinct rows. An assignment dictionary maps `(one-based level, accepted code_index)` to one explicit row_id. Missing accepted-code assignment is UNMAPPED; rejected numerical codes are NOT_APPLICABLE; an explicitly chosen lexical VOID row is LEXICAL_VOID; mapping to a recall/evidential row is rejected as invalid. Existing mapping_status/source wording is not promoted to semantic proof. Evidential metadata is separate and does not encode missingness. `annotate_trace` deep-copies input and annotates each step, never mutating the numerical trace or reference.

`wire.py` owns a reversible ASCII envelope for arbitrary finite JSON objects. API: `encode_record(payload) -> bytes`, `decode_record(record) -> dict`, `copybook_text() -> str`, `roundtrip_with_cobol(records, output_dir) -> dict`. Canonical JSON uses ensure_ascii=True, sorted keys, allow_nan=False and explicit byte-length validation; it preserves Unicode through JSON escapes, not byte truncation. Envelope: EB01 (4 bytes), decimal JSON length (8 ASCII digits), payload SHA-256 hex (64 bytes), 16384-byte ASCII JSON area padded with spaces. Total fixed record size 16460 bytes. Reject oversize input, corrupt length/header/hash/padding, duplicate JSON object keys, NaN/Infinity, and unsupported payload objects. This is JSON transport, NOT decimal fixed-point arithmetic, immutable storage, or cryptographic authentication. `roundtrip_with_cobol` invokes optional installed cobc in a temporary/run directory, generates free-format copybook and a runtime that reads and writes complete fixed-size records, and reports compiler/runtime diagnostics and exact-byte equality. It must not write to raw/evidence specimens. No silent truncation; Unicode and apostrophes round-trip because source literals do not contain user data.

`demo.py` and `tests/test_experiment_bridge_v1.py` integrate these contracts with explicit ILLUSTRATIVE fixtures and supplied reference data. They report real execution and compiler results, not claims about real neural codes. Numerical audit checks must reject a deliberately altered over-threshold-accepted transition, dimension mismatch, stale residual, and missing codebook identity. Integrity hashes detect modification relative to their record; they do not prevent tampering or certify truth.

## Scope

Actual NCM adapters, natural-language semantic evaluation, real dataset calibration, rate/distortion and performance benchmarks, physical transducers, and production claim-table registration remain out of scope. This contract addresses software representation and routing gates, not the remaining empirical/physical gaps.
