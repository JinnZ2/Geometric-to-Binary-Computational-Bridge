# Experiment bridge audit — 2026-11-17

**Usable now: a preserved semantic reference, residual/reconstruction bookkeeping, explicit rejection as a policy, and Kimi's reproducible synthetic RVQ test bench. Not usable as delivered: the original COBOL generator, the proposed NCM semantic adapters, or any physical effort–flow claim.** The originals remain untouched; this note changes the reading, not the specimens.

## The earlier implementation does not match its narration

With the supplied data, the two original nearest-code distances print **0.0574 and 0.7348**, not 0.0608 and 0.6782. The original three-level example emits **three VOIDs**: the first distance is about 0.509902 against a threshold of 0.5, so no reconstruction contribution is accepted. Its advertised sequence and error reductions are not generated by the script. Exact cases are retained in [original_reproduction.json](evidence/original_reproduction.json).

The generator declares a 785-byte record with widths inferred from the supplied JSON. The adapter emits 563 characters, omits RECORD-TYPE, and uses stale widths. Unicode makes character and byte lengths diverge further. The untouched generated copybook fails GnuCOBOL 3.1.2.0 compilation at the unescaped apostrophe in `xagme'a`; the first error is at copybook line 31. Separate language probes show that VALUE initializes mutable data, PIC X assignments can truncate, and decimal scale does not guarantee failure on every loss. A copybook alone is neither an immutable ledger nor an exact-numeric audit pipeline. [Code audit](audit/code-audit.md) and [compiler diagnostics](evidence/original_compiler/original_generated/stderr.txt) retain the details.

The adapters collapse distinct reference rows by using only `gismu` as a key. Recall checks replace mappings for snura, jibni, and zmadu; optimal replaces best. The field itself includes lujvo and cmavo as well as gismu. Empty or mismatched vectors can silently lose coordinates through `zip`; NaN thresholds bypass rejection. The original reserved zero vector competes with real codes, and a shared mutable VOID record can retain a stale rejection reason. These are concrete blockers, not cosmetic issues.

## Kimi supplies a useful numerical bench, with narrower meanings

Kimi's unchanged seed-0 RVQ script reproduced every saved numerical value and verdict on two runs after excluding only runtime and four claim timestamps. It trains four 16-code levels on 2,000 correlated Gaussian vectors and evaluates 1,000 held-out vectors; it is **not a neural NCM model**, loads no Lojban reference, and emits no COBOL record. Full output files are not byte-identical because timing fields change. [Replay evidence](evidence/kimi_reproduction.json) records both comparisons.

Held-out first-level residual squared-norm fraction is **0.24838060886903807** and final fraction is **0.07661369632660063**. There are **985 distinct full code paths out of 1,000**. Independent traversal confirms zero over-threshold accepted snaps on that finite dataset and checks `z = reconstruction + residual` to floating-point tolerance. The non-competing reserved escape symbol is useful in the script's fixed configuration.

Corrections must accompany those results. Its reported 37.8% held-out first-level code-contribution fraction divides by the training signal total; the same-split fraction is about **77.01%**. Neither code norm nor residual norm is a disjoint energy allocation. Its 1.5% statistic is the fraction of redundant samples beyond one representative per path; **2.5%** of samples actually belong to shared-path groups. The integrity claim's `measured=0.0` is hardcoded in the supplied script; the independent audit supplies the missing finite traversal check. Later rejection thresholds are calibrated on ungated residual trajectories, so a target training rejection rate is not guaranteed after earlier rejections.

The omitted-cross-term statistic reproduces: worst relative defect is **1.5036325501281391**. It tests whether the vector split is orthogonal, not physical power conjugacy. The identity is `||z||² = ||reconstruction||² + ||residual||² + 2<reconstruction,residual>`. A nonzero cross term does not prove that every possible energetic model is impossible; orthogonalizing vectors would not establish one either. [Semantic/physics audit](audit/semantic-physics-audit.md) explains the distinction. Invalid inputs and configurable dimensions still need guards before the toy can become a reusable library.

## The NCM premise survives, but not the claimed guarantees

The primary publication is **Next-Concept Modeling: Fast, Parallel Coarse-to-Fine Text Generation**, arXiv:2610.14162v1, a 2026 preprint with official HazyResearch code. Residual VQ and coarse-to-fine generation are supported. Four levels are not a universal property; trained configurations use different depths. Nested dropout retains cumulative coarse prefixes, not standalone finer levels with the coarse levels removed. The paper and inspected encoding path do **not** provide the alleged residual-distance rejection bound or VOID semantics. [1] [2]

A bridge-specific rejection policy is a legitimate experiment, but its threshold needs its own metric, normalization, checkpoint/level identity, and held-out calibration. Learned codes do not become verified Lojban predicates through a handwritten index dictionary. Author-reported H100 benchmark results are not benchmarks of this repository; independent reproduction status remains unresolved here. The [NCM audit](audit/ncm-audit.md) supplies pinned code links and scope.

## Preserve the useful semantic distinctions

Keep source capture, proposed English mapping, recall difference, and absent mapping distinct. `OBSERVED` in the supplied data is a source-capture assertion, not proof of semantic correctness. The three lexical VOID rows describe scoped lookup gaps, not global absence of those concepts from Lojban. No complete dictionary audit was performed.

CLL confirms that `ju'a` avoids specifying a basis, `ca'e` concerns definitions/performatives, and `ru'a` marks an assumption—not a missing-value state. Evidentials describe a statement's basis; they do not certify truth or automatically correspond to physical substrates. URLs and retrieval dates are useful provenance metadata, not cryptographic authentication. [3]

For a subsequent adapter, record identity must be independent of word identity. Numerical acceptance, threshold rejection, absent semantic assignment, and lexical VOID should be separate fields. Retain the vector and accepted contribution, metric and distance, threshold, codebook identity, record role, and provenance rather than encoding them into a truncated reason string.

## What is admitted and what remains held

**Admit to the experiment folder:** unchanged incoming files with a hash manifest; the synthetic RVQ witness in its declared configuration; safe replay harnesses; independent routing and identity checks; explicit negative findings; source-grounded model and language notes. These support further experiments, not production or semantic certification. The preservation tests detect changes; they do not make files immutable.

**Hold outside production registries:** the original generator and adapters, physical coupler/resistance/insulator interpretations, an automatic Lojban ontology, and neural-model performance or dropout guarantees. Deterministic argmin conditional on a codebook is not a zero-parameter physical transformer. Reconstruction plus residual is an additive identity, not a power-conjugate pair. No physical bridge is added. [4]

The received expansion-math note is retained as a separate scope specimen. Its exact-inflation results were not replayed or researched here. [Research gaps](RESEARCH_GAPS.md) identifies the work that would change the held dispositions without rewriting the raw record.
